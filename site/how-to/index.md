---
title: How-to guides
description: Recipes for tasks you already have in mind, each one task from start to finish, in the viewer and from the command line.
---
Each guide solves one task. It assumes aless is installed and that you know your way around a terminal, and it links to the [command line reference](/reference/command-line.html) for every option it uses and to the [keys](/reference/keys.html) for every key.

The guides are in three groups, because aless has two faces. In a terminal it is a viewer, and the second group is about a file open in one: searching it, following it as it changes, copying from it, several files at once. In a shell script, a CI job or an agent's tool call it prints JSON, and the third group is about that. The first group is setting it up. If you have not used aless before, the two [tutorials](/tutorials/index.html) come first, one for each face.
