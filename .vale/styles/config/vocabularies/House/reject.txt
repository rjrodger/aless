# The banned list. Entries are REGEXES, matched case-insensitively on
# word boundaries, and each one fails CI as Vale.Avoid.

# EVERY NON-BLANK LINE IS A PATTERN, these comments included: Vale has
# no comment syntax in a vocabulary file. A heading is safe because its
# text appears on no page, and admin/scripts/prose-gate.cjs reads them
# the same way rather than skipping them, so the two gates cannot come
# to ban different things. A line that is only "#" is NOT safe: it bans
# the character, and reports `owner/repo#13` as an error. Separate
# sections with a BLANK line, never with a bare hash. Each line is a
# regular expression of its own, so a bracket or a parenthesis opened
# on a line closes on the same line.

# Write an apostrophe as `['’]`. A plain `'?` matches `lets` and
# `let's` and walks straight past `let’s`, which is what a word
# processor, a website and most pages produce.

# THIS FILE IS THE SINGLE SOURCE OF TRUTH. admin/scripts/prose-gate.cjs
# reads it rather than holding its own copy, so the fast local gate and
# the CI prose gate cannot disagree. Add a phrase here and both pick it
# up.

# Sources: the house list in STYLE-GUIDE.md, plus the catalogue at
# claudisms.ai and, further down, AiTells. Entries from those lists that
# collide with ordinary technical vocabulary are deliberately NOT here:
# see "What is not banned, and why" in STYLE-GUIDE.md.

# Not filler in the way the rest of this list is: the word is fine in
# ordinary English. It is here because it becomes a verbal tic, as in
# "the honest rendering", "the honest gap" or "keeps the copies honest",
# where it flatters a sentence rather than says anything the sentence
# did not already say.

# exists gets used. A use the author wants kept is approved by editing
# this line, which is visible in review.
