title: Tutorials
description: Lessons that take you through aless from the start, one step at a time, and show what aless draws at every step.
---
Start here if you have not used aless before. Each tutorial is one lesson that you follow from start to end, and each takes about 10 minutes. Each lesson works on one file, so its first step is to download that file. Every step shows what aless draws.

The lessons build on each other, so take them in this order:

1. [Look around a file in the viewer](/tutorials/viewer.html) opens an API description, moves through it, folds it, searches it, and copies a path.
2. [Watch the changes to a file](/tutorials/changes.html) changes a file while aless shows it, and reads the marks aless puts on each change.
3. [Look back through the versions of a file](/tutorials/history.html) saves a file several times, and steps back through the versions aless keeps.

If you already have a task in mind, the [How-to guides](/how-to/) take you to that task sooner.
